# Tymerr

Tymerr is a lightweight, personal study-tracking web app designed to make focused studying easier to manage, track, and understand.

It brings the essential parts of a study workflow into one clean interface — from starting a focused study session to reviewing detailed analytics and planning what to study next.

##  Features

* **Study Timer** — Start, pause, resume, and stop focused study sessions with subject-based tracking.
* **Session Logging** — Automatically records study sessions so your progress can be reviewed later.
* **Analytics Dashboard** — View study time, trends, activity patterns, calendars, and subject-wise performance.
* **Subject Management** — Create and manage the subjects you are currently studying.
* **Planner** — Organize upcoming study tasks and keep track of what needs to be done.
* **Subject Deep Dive** — Explore detailed study statistics for individual subjects.
* **Admin Dashboard** — Monitor registered students, total study activity, active usage, and individual student data.
* **Developer Tools** — Built-in tools for generating test history, creating sample sessions, testing midnight-crossing sessions, and simulating timer-related scenarios.
* **Data Management** — Includes tools for exporting and resetting data where appropriate.
* **Responsive Interface** — Designed to remain simple, clean, and usable across different screen sizes.

##  Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Firebase Authentication
* Cloud Firestore
* Firebase Hosting / Web Hosting

Tymerr intentionally keeps the frontend lightweight and avoids unnecessary frameworks, making the project easy to understand, modify, and extend.

##  Purpose

Tymerr was built around a simple idea: studying should be easy to start, while progress should be easy to understand.

Instead of relying on scattered timers, notes, and spreadsheets, Tymerr combines studying, session history, planning, and analytics into a single focused workspace.

The project is also structured with separate administrative and developer functionality, making it easier to test the application, inspect usage, and continue developing new features.

## Project Status

Tymerr is an evolving project and serves as both a functional study tracker and a foundation for experimenting with productivity-focused features, analytics, and real-time data management.
